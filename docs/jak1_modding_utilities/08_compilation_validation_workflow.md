# 🇬🇧 English Version

## Compilation & Run Steps

1. **Select Active Game:**
   ```bash
   task set-game-jak1
   ```
2. **Compile Code in OpenGOAL REPL (`task repl`):**
   ```lisp
   (mi)
   ```
3. **Launch the Game:**
   ```bash
   task boot-game
   ```
